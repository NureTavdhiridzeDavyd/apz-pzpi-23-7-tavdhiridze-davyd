Опис прийнятих інженерних рішень:
Для web-застосунку HiveTrack Web було обрано React та Vite, оскільки вони дозволяють швидко створити зручний односторінковий інтерфейс і легко розділити його на компоненти. Застосунок має рольову структуру. Після авторизації користувач отримує доступ лише до своїх функцій: учень бачить групу, відвідуваність, тести й сповіщення; інструктор — свої заняття та учнів; адміністратор — керування групами, заняттями, зарахуваннями, сповіщеннями та аудитом. Взаємодія з серверною частиною відбувається через REST API у форматі JSON. Для захисту доступу використовується JWT-токен, який зберігається у локальному сховищі браузера. Інтерфейс підтримує українську та англійську мови, а дані відображаються у вигляді карток, списків і форм. Також реалізовано базові функції експорту та імпорту налаштувань для адміністрування системи.
