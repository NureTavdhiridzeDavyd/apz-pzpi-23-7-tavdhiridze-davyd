1 КОРОТКИЙ ОПИС ПРОЄКТУ
     HiveTrack — це програмна система для цифровізації роботи автошколи. Проєкт призначений для організації навчального процесу, контролю груп, занять, відвідуваності, тестів ПДР, сповіщень та IoT-даних з навчального автомобіля.
     Система складається з кількох основних компонентів: серверної частини на Node.js / Express, хмарної бази даних Aiven MySQL, web-застосунку на React / Vite, мобільного Android-застосунку на Kotlin, IoT-модуля та конфігурації масштабування backend через Docker і Nginx.
     У системі передбачено три основні ролі користувачів: учень, інструктор та адміністратор. Кожна роль має власний набір функцій. Учень може переглядати свою групу, відвідуваність, тести та сповіщення. Інструктор працює зі своїми заняттями, учнями та відвідуваністю. Адміністратор керує групами, заняттями, зарахуваннями, сповіщеннями, аудитом і статистикою.

ВИСНОВКИ
     У результаті виконання лабораторних робіт було створено цілісний прототип системи HiveTrack для цифровізації роботи автошколи. Проєкт включає backend, базу даних, web-клієнт, мобільний клієнт, IoT-модуль та базове масштабування серверної частини.
     Система демонструє роботу з трьома ролями користувачів: учнем, інструктором та адміністратором. Кожна роль має власні функції, а всі компоненти взаємодіють через спільний REST API.
     Проєкт є навчальним прототипом, але його можна розширювати. У майбутньому доцільно додати повноцінний банк питань ПДР, детальнішу IoT-аналітику, push-сповіщення, покращену безпеку та ширшу статистику.
